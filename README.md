# 📸 Smart Photobooth System

An interactive web-based photobooth system that simulates a real-world automated photo booth experience, including payment, camera capture, customization, and instant print workflow.

---

## 🚀 Features

- 💳 Payment simulation (UPI / Razorpay-style UI)
- 📷 Live camera preview & capture
- ⏱️ Countdown-based photo capture (4 shots)
- 🎞️ Polaroid-style image generation
- 🎨 Style customization (classic, rounded, strip)
- 🖨️ Print simulation workflow
- 📊 Step-by-step user interaction flow

---

## 🧠 Workflow

1. User starts session  
2. Payment is simulated  
3. Camera opens → 4 photos captured  
4. User selects style  
5. Photos processed into polaroid format  
6. Print simulation completes
